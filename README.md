# Outbreak 爆发

**一个关于真实生理、免疫反应、本草药物与病原传染的 Minecraft 模组。**

A Minecraft mod about **physiology, disease, pharmacology and contagion**.

面向版本：**Minecraft 26.3**（Fabric，Scala 3.9 / Kotlin 2.4 / Java 25）。

---

## 核心特色

- **真实的感染与免疫机制**：吃坏东西不会立刻掉血，病原体在体内按逻辑斯蒂（Logistic）曲线繁殖；免疫系统的清除效率呈钟形曲线——炎症过低免疫不工作，炎症失控则引发免疫风暴损伤机体。
- **动态生理平衡系统**：引入 10 格独立口渴条，以及钠、钾、镁、钙、磷五项微量电解质与碘稳态。维持体内平衡，抵御高热脱水与失衡症状。
- **本草医药与药物干预**：
  - **柳树**：河畔生态，采剥树皮并用炼药锅熬制柳树皮汤，提取水杨苷解热镇痛；
  - **麻黄**：干旱群系药植，经砂轮研磨或剪刀切碎后制成“麻黄碱药水”，提供速掘提神；
  - **黄连与黄柏**：传统苦寒本草，富含黄连素，可生食或砂轮研磨酿制黄连/黄柏药水，特异性阻断细菌增殖；
  - **甘草**：抗病毒本草，富含甘草酸，可生食或砂轮研磨酿制甘草药水，特异性阻断病毒复制；
  - **曼陀罗与裸伞**：探索危险的抗胆碱能药物与精神致幻菇类，体验真实的散瞳与视效扭曲；
  - **地塞米松**：现代强效糖皮质激素注射液，力挽狂澜抑制高危细胞因子风暴。
- **工艺与农副拓展**：
  - 岩盐采矿、砂轮多级粉碎与浓缩制盐；
  - 玻璃发酵罐与冷凝管蒸馏系统，酿造不同浓度的乙醇酒液；
  - 完整的柳木建材套装、自然倒映水面的垂柳树木生态。

## 环境与构建

| 组件 | 版本要求 |
| --- | --- |
| Minecraft | **26.3** |
| 加载器 | Fabric Loader ≥ 0.19.5，Fabric API ≥ 0.161.0+26.3 |
| 开发环境 | Java 25，Kotlin 2.4.20，Scala 3.9.0 |
| 构建工具 | Gradle 9.7.1 + Fabric Loom 1.17.21 |

```powershell
# 编译构建
gradle build

# 运行开发环境客户端与服务端
gradle runClient
gradle runServer

# 重新生成全量数据与贴图（幂等）
tools\gen_data.cmd
tools\gen_textures.cmd
```
