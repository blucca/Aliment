# Outbreak 爆发

**一个关于生理、疾病、药物与传染的 Minecraft 模组。**

A Minecraft mod about **physiology, disease, drugs and contagion**.

---

## 这个模组是什么

它把"生病"变成一件有过程的事。吃坏东西**不会**立刻掉血——病原体在体内按 logistic 增长，
免疫系统按一条钟形曲线决定清除速度：**炎症太低免疫罢工，太高则免疫风暴反过来伤害你**。
你能做的是控制炎症（柳树皮汤里的水杨苷、地塞米松注射剂），把水、电解质、碘和体温维持
在各自的稳态里，并尽量别喝沼泽水、别徒手摸蝙蝠。

| 系统 | 一句话 |
| --- | --- |
| **传染** | 生肉 / 腐肉 / 毒马铃薯 / 生柳树皮汤 30% 细菌；**任何生物**贴近 2 格内每秒 20% 传病毒；**免疫抑制时每秒 15% 凭空**感染细菌 |
| **免疫** | 五种炎症介质加权成炎症指数；免疫能力是钟形曲线，过低过高都会让感染失控 |
| **药物** | 水杨苷（柳树皮汤，COX 抑制剂，**同时是退烧药**）与地塞米松注射剂；**过量会免疫抑制**，而免疫抑制会自己招来感染 |
| **重症** | 载量 ≥ 60 起直接受到**魔法伤害**（护甲无效），载量越高越快 |
| **生理** | 水量 / 10 格口渴条；五项电解质（**mmol/L**）+ 碘（**µmol/L**），用真实参考范围，两侧都是病 |
| **体温** | 36.0–38.5 舒适；≥38.5 发烧（泛红 + 扭曲），≥40 超高热（再加动态模糊），≤36 失温（+缓慢） |
| **柳树** | 河边生成、树干向水倾斜、树冠垂下柳条；柳木全套方块 + 船 + 告示牌 |
| **盐业** | 岩盐矿 → 粗盐 → 粗盐粉 → 粗盐水炼药锅（蒸发）→ 盐粉，以及一整套咸味食物 |
| **口渴** | 带盐与不带盐的水、汤各有生理后果；**喝两杯盐水就会越过钠的参考范围**；海水是**高渗水**而不是脏水 |

## 构建

仓库里没有 wrapper，用本机的 Gradle 9.7.1：

```powershell
gradle build          # 产物在 build/libs/
gradle runServer      # 开发用服务端（自检需要临时启用入口点，见 tools/README.md）
gradle runClient
```

数据与贴图都是**生成**的，可以随时重新生成（两者都是幂等的，且以 Minecraft jar 里的
原版 JSON / 素材为模板）：

```powershell
tools\gen_data.cmd        # 全部 data / assets JSON
tools\gen_textures.cmd    # 全部贴图
```

## 验证

以及真实的方块交互（剥皮、砂轮、炼药锅、60 秒煮汤、树苗生长与倾斜）。
实测输出抄在 [`PHYSIOLOGY.md`](PHYSIOLOGY.md#验证) 与 [`WILLOW.md`](WILLOW.md#验证) 里。
